# Periodic Table of the Elements

An interactive, single-file periodic table — all 118 elements, with detail panels, search, and category filtering.

**→ [View live](https://hainguyenee.github.io/periodic-table/)**

---

## Features

- **All 118 elements** in the standard 18-column / 7-period layout, with lanthanides and actinides on their own rows below
- **Click any element** for a detail panel: atomic mass, electron configuration, electronegativity, melting & boiling points (K and °C), density, discovery, phase at STP, and a short summary
- **Search** by name, symbol, or atomic number — matches highlight in gold, non-matches dim
- **Filter by category** — toggle any of 11 element categories on/off via the legend (alkali, alkaline earth, transition, post-transition, metalloid, nonmetal, halogen, noble gas, lanthanide, actinide, unknown)
- **Keyboard shortcuts** — `/` jumps to search, `Esc` closes the panel
- **Responsive** — adapts cleanly from desktop down to mobile

| **Deps**     | None bundled (Google Fonts loaded via CDN)                   |
| **Type**     | Cormorant Garamond (display), Manrope (body), JetBrains Mono (data) |
| **Hosting**  | GitHub Pages                                                 |

## Run locally

Clone and open `index.html` in any browser — no build required.

```bash
git clone https://github.com/HaiNguyenEE/periodic-table.git
cd periodic-table
open index.html
```
